## How to Run the Notebook
1. Clone this repository:
   ```bash
   git clone <repo-url>
   cd CPE_Project_Group_IUTO
   ```
2. (Recommended) Create and activate a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # on Windows: venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Download the dataset using the link in `data/data_link.txt` and place it in the `data/` folder (or adjust the path in the notebook).
5. Open and run `project_notebook.ipynb` in Jupyter Notebook, JupyterLab, VS Code, or upload it to Google Colab.
